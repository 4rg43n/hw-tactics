# NULLRELAY Tactics

A small turn-based tactics game set aboard NULLRELAY_091, the station from [hello-world-game](https://github.com/4rg43n/hello-world-game). Play Vale, an intrusion tech caught on a deck overrun by Reclaimed station security.

Open `index.html` in a browser. The game runs from the file and needs no installation, server, or internet connection.

- **WASD** or the on-screen arrows move one tile. Bump crew to talk or Reclaimed to strike.
- **Click or tap** a Reclaimed to fire. An outline marks enemies in range and in line of sight.
- **Space** or **Pass** waits for a round. **Restart** resets the deck.
- Clear all four Reclaimed before Vale's integrity reaches zero.
